description: how to run the ECHO forensic dashboard
---

To run the ECHO dashboard, follow these simple steps:

1. **Locate the file**:
   Navigate to the `dashboard` directory in your project folder:
   `c:\Users\samyu\OneDrive\Desktop\ECHO\dashboard\echo_dashboard.html`

2. **Open in Browser**:
   - Right-click the `echo_dashboard.html` file and select **Open with** > **Google Chrome** (or your preferred modern browser).
   - Alternatively, you can simply double-click the file if your default browser is set.

3. **Backend Connection (Optional)**:
   - Ensure your Python FastAPI backend is running on `http://localhost:8000`.
   - If the backend is offline, the dashboard will seamlessly switch to **High-Fidelity Mock Data** mode so you can still demonstrate all features.

4. **Authentication**:
   - Once the page loads, click the **AUTHENTICATE & INITIALIZE SYSTEM** button on the legal gate modal to reveal the dashboard.
